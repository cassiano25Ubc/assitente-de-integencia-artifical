# projeto: interface IA Chat - Eren Yeager

o projeto é uma interface inicial de chat com IA ,semelhante a página do ChatGPT, CLAUDE E ETC..

## Aspectos visuais
A tela deve ser escura(dark) e o campo de busca no centro da tela .

O tema principal do projeto é em tom azul marinho

Dentro da área do campo de mbusca dev ter também :
- Na parte inferior esquerda :
 - Botão (que ativa e desativa ) dizendo  " pensamento profundo"
 - Botão (que ativa e desativa) dizendo " busca inteligente "
- Na parte inferior direita :
 - Botão enviar , arredondado

A cima da área do campo de busca dev ter 2 opcões  (como tabs) para selecionar:

- Rápido
- Especialista

Acima deles ,o nokme do projeto : Eren Yeager

 ## Aspectos técnicos 

 O projeto usa vite + React + typescript +Tailwind

 O porjeto deve usar componetes na pasta src/components, devidamente organizados e sem repetir componente desnecessáriamente.

 por hora não há nenhuma ação de busca.
