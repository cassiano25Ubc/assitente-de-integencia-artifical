# 🤖 Eren Yeager

Interface de um assistente de inteligência artificial desenvolvida com **React, TypeScript e Tailwind CSS**, com foco em uma experiência moderna, simples, acessível e responsiva.

O projeto apresenta uma interface inspirada em ferramentas de IA, permitindo ao usuário selecionar diferentes modos de interação e configurar opções como **pensamento profundo** e **busca inteligente**.

> **Status:** Protótipo de interface. A integração com inteligência artificial, busca e envio de mensagens ainda não está implementada.

---

## ✨ Funcionalidades

* ⚡ Seleção entre os modos **Rápido** e **Especialista**.
* 🧠 Controle para ativar ou desativar o **Pensamento profundo**.
* 🔎 Controle para ativar ou desativar a **Busca inteligente**.
* 💬 Campo para digitação de mensagens.
* 🚫 Botão de envio desabilitado enquanto a integração com IA não está disponível.
* 📱 Interface responsiva com abordagem **mobile-first**.
* ♿ Controles desenvolvidos considerando acessibilidade e navegação por teclado.
* 🎨 Interface com tema escuro e identidade visual em tons de azul-marinho.

## 📋 Requisitos

Antes de executar o projeto, certifique-se de ter instalado:

* [Node.js](https://nodejs.org/) **20.19+ ou 22.12+**
* **npm**

---

## 💻 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/cassiano25Ubc/assitente-de-integ-ncia-artifical.git
```

### 2. Entre na pasta do projeto

```bash
cd assitente-de-integ-ncia-artifical
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

Depois disso, o Vite exibirá no terminal o endereço local para acessar a aplicação no navegador.
